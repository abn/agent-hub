# Product screenshots

The main feature screens of the human surface, captured from a seeded scratch
hub at 1440x900 and 390x844 in both themes. The filenames are
`<route>-<width>-<theme>.png`. They are committed artifacts: the
`capture-wiki-screenshots` skill refreshes them when a screen changes, and
each image is looked at before it lands.

The set holds every screen the router registers plus the dialogs behind a
control: the wiki's editor, a page's History and the change log, and the new
project, delete project, end session, prune, issue token and revert dialogs.
Issue a token opens over the agent detail stage, which a phone does not reach,
so it is carried at the desktop width alone; every other capture is taken at
both widths in both themes.
