# Get started

Pick the path that matches what you have. Each one ends with a running hub and
a connected agent; you never have to read a path you are not going to take.

* [Try it in five minutes](try-it.md) - Run the hub on your own machine and open the app for the first time
* [Choose your setup](choose-your-setup.md) - Pick how to run the hub and how machines reach it, then follow one install
* [Install and run the hub](install.md) - Install the container, a release binary, or from source, and run it
* [Open the app and log in](first-login.md) - Reach the human surface, paste the admin token, and install the app
* [Connect your first agent](connect-first-agent.md) - Create an agent, get its token, wire its harness, and prove the MCP link
* [Where to go next](where-next.md) - A short map from a running hub to the rest of the wiki
