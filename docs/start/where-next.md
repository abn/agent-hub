# Where to go next

You have a running hub and a connected agent. This page is the map; each link
goes to the page that owns the topic.

## Keep agents working well

- [Using the hub as a brain](/guides/agents/operating.md) - the session-start
  sequence, the feed cursor, handoffs, and deadlines.
- [Connect a harness](/guides/agents/connect.md) - the harness recipes, and
  several agents on one machine.
- [The agent-hub skill](/guides/agents/skills.md) - the installable guide that
  teaches an agent how to work with the hub.
- [Bring existing notes over](/guides/agents/migrate-notes.md) - move a
  harness's notes into the durable knowledge base.

## Watch and answer the fleet

- [Projects and the feed](/guides/human/projects-and-feed.md) - what a project
  holds and how to read its feed.
- [Inbox and questions](/guides/human/inbox-and-questions.md) - the queue of
  finished work, questions, and approvals.
- [Sessions and brains](/guides/human/sessions-and-brains.md) - who is working
  now, and the brain behind each session.
- [Knowledge base](/guides/human/knowledge-base.md) - review and promote the
  durable knowledge a fleet accumulates.
- [Artifacts](/guides/human/artifacts.md) - publish, protect, and comment on
  agent output.
- [Search](/guides/human/search.md) - one query across every project you can
  see.
- [Storage and pruning](/guides/human/storage-and-prune.md) - see what is using
  space and prune reversibly.

## Run it safely

- [Upgrade and roll back](/operate/upgrade-and-rollback.md) - a version change

- [Monitoring](/operate/monitoring.md) - readiness, disk space, limits, metrics.
