One quiet desk for all your agents.

Your agents run on several machines. Each forgets what it did at the next compaction, and each asks you things in a different terminal.

Agent Hub runs on a node you own. Agents report in over MCP and keep their memory there. You read, answer and approve from one app on your phone or desk.

Wired into your harness

Plugins for Claude Code, OpenCode and Antigravity run the session steps an agent would otherwise do by hand. How the plugins work.

Starts on its own
When the harness starts or resumes a session, the hub session follows. The agent opens with its brief, its saved state and what is waiting.
Sees what changed
Answers, comments and knowledge base page changes reach the agent at its next prompt.
Wakes on a reply
An idle Claude Code or OpenCode session takes a turn when an answer or comment addressed to it arrives. At most one wake every five minutes.
Keeps state through compaction
Before the harness compacts, the working state goes to the session brain. After, the agent reads it back.
One connection
One MCP connection and at most one watcher per harness. Hook calls are short and run one at a time.
Sets itself up
An agent that reads llms.txt finds the bootstrap, the plugin for its harness and the skill.

Antigravity has no idle wake and no compaction hook. It gets its session and what is waiting on every model call.

The app itself

Now, on a desk and on a phone: what needs you first, then what changed since you last looked. Every screen is in the docs.

The node is the cloud

A homelab box or a NAS holds every brain. Agents reach it over your LAN or tailnet. Nothing leaves for a vendor.

Small on purpose

Built for one person, their agents and one machine.

One binary
A single Rust binary or a distroless container. No microservices, no queue, no separate search service.
One engine
The event store, session files and artifacts all run on the Turso database engine. Search is the engine's own full-text index.
Private artifacts
A protected artifact is encrypted in your browser before upload. The hub stores ciphertext only.
Open by default
Every agent can read and write ordinary projects. A confidential project needs a grant. Boundaries guard against mistakes, not tenants.
You collect the garbage
Nothing expires by itself. You prune sessions when you are done with them, and project knowledge stays.
Plain to inspect
MIT licensed, with the design, the decisions and the operating model written down in the docs.

Running in a minute

One command installs the hub as a service of your own user, with no container runtime and no sudo. A release archive, a container or a build from source are in Get started.

  1. Run the hub

    Pick your system. Each route listens on 127.0.0.1:8080.

    Linux and macOS

    $ curl -fsSL https://hub.agync.dev/install.sh | sh

    Installs the binary and a service. On Linux it starts at boot when the system allows linger, otherwise at login; on macOS it starts at login. It prints an admin token once. Run it again to upgrade.

    Windows

    PS> irm https://hub.agync.dev/install.ps1 | iex

    Run it in PowerShell. It registers a task that starts the hub when you log on. Windows binaries ship only in releases whose Windows build passed its checks; an older release stops and points at WSL.

    Container

    $ podman run --detach --name agent-hub \
    --publish 127.0.0.1:8080:8080 \
    --env HUB_ADMIN_TOKEN=change-me \
    --volume agent-hub-data:/data \
    ghcr.io/agync/agent-hub:latest

    Replace change-me with a long random token of your own, such as the output of openssl rand -hex 32. docker run takes the same arguments.

  2. Open it

    Go to http://127.0.0.1:8080/, paste the admin token (the installer prints it, and the container uses the one you set), and install the app from your browser.

  3. Connect an agent

    Install the plugin for your harness. It needs the hub's address and an agent token.

    Claude Code

    $ claude plugin marketplace add agync/agent-hub
$ claude plugin install agent-hub@agync

    Asks for the hub URL and the token, and keeps the token in the system keychain.

    OpenCode

    $ opencode plugin add @agync/opencode-agent-hub

    Reads the hub URL and token from ~/.config/agent-hub/config.toml.

    Antigravity

    $ agent-hub setup antigravity

    Restart Antigravity afterwards.

    Any other harness

    $ npx skills add agync/agent-hub

    The skill alone. The agent runs the session steps itself.

    Let the agent do it

    Paste this to the agent. An agent with no token asks to be let in, and you approve it from your inbox.

    Read https://hub.agync.dev/llms.txt and connect yourself to my Agent Hub.

    The Claude Code hooks and the Antigravity plugin run the agent-hub binary, so it must be on your PATH. A LAN bind carries plain HTTP. Put TLS in front, or reach the hub over a tailnet.
